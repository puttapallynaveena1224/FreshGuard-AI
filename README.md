# 🌿 FreshGuard AI

**Zero-Waste Grocery — An Agentic AI Approach to Perishable Demand & Shelf-Life Management**

FreshGuard AI is an agentic AI system designed to solve one of retail's most expensive and environmentally damaging challenges: **perishable food waste and out-of-stock shelves**.

Traditional grocery store reordering uses rigid min/max thresholds. When customer demand surges or drops, stores end up with either empty shelves (lost revenue) or spoiled produce that ends up in landfills. FreshGuard AI deploys a cooperative multi-agent system where specialized AI agents continuously analyze demand velocity, batch-level expiration dates, stockout threats, and dynamic discounts—coordinated with a **Human-in-the-Loop (HITL)** approval flow.

---

## ⚠️ Important Notices & Ethical Guardrails

1. **Synthetic Sample Data Notice**:
   All retail stores, supplier agreements, product batches, inventory quantities, and sales logs in this repository are **100% synthetic demonstration data** created strictly for educational and hackathon evaluation purposes.

2. **Simulated Estimates**:
   Any metric such as "projected waste reduction", "carbon offset", or "financial savings" generated by FreshGuard AI is a **simulated model projection** designed to illustrate multi-agent reasoning, not an empirical guarantee of real commercial performance.

3. **Strict Food Safety Policy**:
   FreshGuard AI enforces a **zero-tolerance food safety guardrail**:
   - Batches past their expiration date are strictly flagged as `EXPIRED_UNSAFE`.
   - Expired batches are **never** eligible for markdowns or retail sale.
   - The system automatically triggers a mandatory `DISPOSAL / COMPOSTING` notification for any expired batch.
   - Dynamic discounts are **only** applied to wholesome, safe items that are 1–3 days prior to expiration to encourage sell-through before spoilage occurs.

## 📖 Explanation of Current Files (In Plain English)

| File | Purpose in Simple Language |
| :--- | :--- |
| **`requirements.txt`** | A shopping list of Python packages needed to run the project (`streamlit` for the web dashboard, `pandas` for handling spreadsheets, `numpy` for math, and `plotly` for interactive graphs). |
| **`data/generate_sample_data.py`** | A self-contained Python program that creates realistic fake grocery data. It runs without needing extra tools installed and enforces food safety rules. |
| **`data/stores.csv`** | Contains simulated store profiles: a busy downtown supermarket (`STR-001`), a large suburban supercenter (`STR-002`), and a small transit grab-and-go shop (`STR-003`). |
| **`data/suppliers.csv`** | Contains supplier information: delivery wait times (lead days), minimum order quantities (MOQ), wholesale cost, margin floors, and shelf lives for avocados, strawberries, spinach, milk, yogurt, sourdough, chicken, and beef. |
| **`data/inventory_batches.csv`** | Represents real boxes and packages currently sitting on refrigerated store shelves. Tracks exact lot numbers, days until expiry, and safety status (`SAFE_FRESH`, `SAFE_APPROACHING_EXPIRY`, or `EXPIRED_UNSAFE`). |
| **`data/sales_history.csv`** | Historical cash-register receipts over 14 days showing how demand changes throughout the week (for example, higher sales on weekends). |

## 🚀 Beginner-Friendly Setup Instructions

### Prerequisites
Make sure you have **Python 3.9 or newer** installed on your system.

### Step 1: Open Terminal in Project Directory
Navigate to the project folder:
```powershell
cd "c:\Users\putta\Desktop\FreshGuard AI"
```

### Step 2: (Optional but Recommended) Create a Virtual Environment
A virtual environment keeps project dependencies isolated from the rest of your computer:
```powershell
python -m venv venv
```
Activate it:
- On Windows PowerShell:
  ```powershell
  .\venv\Scripts\Activate.ps1
  ```
- On Windows Command Prompt (cmd):
  ```cmd
  venv\Scripts\activate.bat
  ```

### Step 3: Install Required Packages
*(Ask your AI assistant or run this command when ready):*
```powershell
pip install -r requirements.txt
```

### Step 4: (Optional) Re-generate Sample Data
The repository already includes pre-built sample CSV files. If you ever want to reset or generate fresh random sample data, run:
```powershell
python data/generate_sample_data.py
```
